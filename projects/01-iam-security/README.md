# Project 01 — AWS IAM Security Fundamentals

## Project Overview

This project documents hands-on experience with AWS Identity and Access Management (IAM), focusing on secure access management, authentication, authorization, and least-privilege security practices.

**Learning Resource:** Neal Davis — AWS Certified Solutions Architect Associate (SAA-C03)

**WGU Course:** D319 — AWS Cloud Architecture

**Project Status:** In Progress

## Project Objectives

- Understand AWS IAM users, groups, roles, and policies.
- Explore authentication and authorization.
- Implement least-privilege access controls where supported.
- Understand multi-factor authentication (MFA).
- Configure and validate secure AWS CLI access.
- Document security best practices and architectural decisions.

## Architecture and Security Considerations

This project will emphasize:

- Least-privilege access
- Secure authentication
- Role-based access
- Temporary credentials where supported
- Protection of AWS account credentials
- Monitoring and verification of permissions
